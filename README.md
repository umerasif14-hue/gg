# GG

GG is an independent browser-based game directory.

## Current features

- Search and category filters
- A starter directory of game listings
- Add games using an HTTPS embed URL
- Open supported embedded games inside the GG viewer
- Remove custom entries
- Export and import custom game lists as JSON

## Important notes

- GG is hosted as a static GitHub Pages site. Custom games are saved in the current browser using local storage; they are not automatically shared with other visitors or devices.
- The starter listings open a search for the game in a new tab. They are not guaranteed embedded game URLs.
- A custom game only opens inside GG if its provider permits iframe embedding. Some providers block this.
- GG does not proxy, relay, or bypass school or network restrictions.
- This is an independent project and is not affiliated with any school, Canvas, or game publisher.

## Sharing your custom library

Use **Export my games** on the GG page to save a JSON file. On another browser/device, use **Import games** and select that file.
